# X_O_Game
# Tic-Tac-Toe Web Game 

A simple, responsive Tic-Tac-Toe game built for the web — playable right in your browser.

## 🔗 Live Demo
👉 [Play it here](https://keerthana-2-cse.github.io/Ruby_game/)

##  How to Play
- Built for **2 players**
- Player **X** goes first
- Tap/click a cell to place your mark
- The game automatically detects a **win** or **draw**
- Hit the **Reset** button to start a new round

##  Tech Used
- **HTML** – structure
- **CSS** – styling and layout
- **JavaScript** – game logic and interactivity

##  Origin Story
This project started as an **Android app built with MIT App Inventor**, and was later **ported to the web** using HTML/CSS/JS — a good exercise in taking a mobile-first idea and making it cross-platform.

##  Getting Started (Local Setup)
1. Clone the repo:
   \`\`\`bash
   git clone https://github.com/keerthana-2-cse/Ruby_game.git
   \`\`\`
2. Open `index.html` in your browser — that's it, no build step needed.
